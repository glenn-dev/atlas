# Atlas Principles

1. **The user owns the data.** Data must remain exportable and understandable without a specific AI provider.
2. **Human approval is the default.** Important mutations and automated actions require explicit review.
3. **Auditability over magic.** Atlas should record sources, changes, and important decisions.
4. **Local-first where practical.** Core data and basic operations should be capable of running locally.
5. **Replaceable components.** Models, databases, and external services should be swappable behind clear interfaces.
6. **Real use before abstraction.** New concepts are introduced because an actual workflow requires them.
7. **Documentation is part of the product.** Architecture, decisions, and operating procedures evolve with the code.
8. **Confidentiality boundaries matter.** Employer secrets, credentials, customer information, and proprietary code must not enter personal Atlas storage.
9. **Testing protects memory.** Features that transform or delete knowledge require automated tests.
10. **Atlas assists judgment; it does not replace it.**
