# Diagnose Atlas Task

1. Read `AGENTS.md`.
2. Read `.ai/context.md` and `.ai/tasks/current.md`.
3. Inspect and reproduce the reported problem when possible.
4. Gather evidence from relevant code, configuration, logs, tests, and Git history.
5. Explain the verified root cause, distinguishing facts from hypotheses.
6. Do not modify files until the diagnosis is presented.
7. Propose the smallest fix that satisfies the task and acceptance criteria.
